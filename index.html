Connect to your Grok Build agent

This iPhone app is a mobile client. Your Grok Build agent runs on a Mac, PC, Linux machine, or server and exposes its ACP WebSocket endpoint.
Tip: in Safari, use Share → Add to Home Screen after hosting this folder.
Mobile safety & connection
The mobile client does not store your agent secret on a server. It is kept in this browser session only. For an internet-facing server, use wss://, a strong secret, authentication, and restrictive Grok permission rules. Avoid exposing a raw agent endpoint to the public internet without an access-control layer.
